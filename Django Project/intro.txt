Django - Python Framework
Django Architecture: MVT
M - Model (DB)
V - View (Logical or Backend)
T - Template (Design or Frontend)

By default, Django uses LocalDB - 

Folder Structure:

manage.py -- Controlling the entire django project

settings.py -- Configuration purpose - DB & Mail

routes or navigation links are written in urls.py

logical part is written in views.py

For making sub-application:

python manage.py startapp app_name

python manage.py makemigrations - Preparing the table db schema

python manage.py migrate - Creation of table in DB

models.py file is used to create the schema for our table
